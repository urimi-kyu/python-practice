# 7세트: 5문제 (하루치)

`solution07.py` 파일의 각 함수 안에 있는 `pass`를 지우고 코드를 작성하세요.
**`test_set07.py`(채점 파일)는 고치지 마세요.**

코딩테스트에 자주 나오는 **슬라이딩 윈도우 / 누적합**을 연습해요.
- 누적합(prefix sum): `prefix[i]` = 앞에서 `i`개의 합으로 미리 만들어 두면, 구간 합을 `prefix[끝+1] - prefix[시작]` 한 번의 뺄셈으로 구할 수 있어요.
- 슬라이딩 윈도우: 구간(창)을 한 칸씩 밀면서, **빠지는 값은 빼고 들어오는 값은 더해** 처음부터 다시 계산하지 않아요.
- 창의 크기가 정해져 있지 않은 문제는 **두 포인터**(`left`, `right`)로 창을 늘렸다 줄였다 해요. (3번, 5번)

### 1. `max_window_sum(nums, k)` — 길이 k 구간의 최대 합 (난이도: 쉬움)
정수 리스트 `nums`에서 **연속한 `k`개**를 골랐을 때 만들 수 있는 합 중 **가장 큰 값**을 돌려주세요. (`1 <= k <= len(nums)`, 음수가 있을 수 있어요)
```
max_window_sum([1, 2, 3, 4, 5], 2)        → 9     # 4 + 5
max_window_sum([2, -1, 3, -4, 5], 3)      → 4     # 2 + -1 + 3
max_window_sum([-3, -1, -2], 2)           → -3    # -1 + -2
max_window_sum([7], 1)                    → 7
```
> 힌트: 처음 `k`개의 합을 구한 뒤, 창을 한 칸 밀 때마다 `+ nums[들어오는 위치] - nums[빠지는 위치]`로 합을 갱신하면서 최댓값을 기록해요.

### 2. `range_sums(nums, queries)` — 구간 합 여러 번 구하기 (난이도: 쉬움)
정수 리스트 `nums`와 질문 목록 `queries`가 주어져요. 각 질문은 `[l, r]`이고, **`nums[l]`부터 `nums[r]`까지(양 끝 포함)의 합**을 뜻해요. (`0 <= l <= r < len(nums)`) 질문 순서대로 답을 **리스트**로 돌려주세요. 질문이 없으면 `[]`이에요.
```
range_sums([1, 2, 3, 4, 5], [[0, 2], [1, 3], [4, 4]]) → [6, 9, 5]
range_sums([5, -2, 7], [[0, 2], [1, 1]])             → [10, -2]
range_sums([3], [[0, 0]])                             → [3]
range_sums([1, 2, 3], [])                             → []
```
> 힌트: 질문마다 `sum(nums[l:r+1])`을 하면 질문이 많을 때 느려져요. 먼저 `prefix = [0]`에서 시작해 `prefix[i+1] = prefix[i] + nums[i]`로 누적합을 만들고, 답은 `prefix[r+1] - prefix[l]`이에요.

### 3. `longest_unique_substring(s)` — 중복 없는 가장 긴 부분 문자열 (난이도: 보통)
문자열 `s`의 **연속한 부분 문자열** 중, **같은 글자가 두 번 나오지 않는** 가장 긴 것의 **길이**를 돌려주세요. 빈 문자열이면 `0`이에요.
```
longest_unique_substring("abcabcbb") → 3    # "abc"
longest_unique_substring("bbbbb")    → 1    # "b"
longest_unique_substring("pwwkew")   → 3    # "wke"  ("pwke"는 연속이 아니라서 안 돼요)
longest_unique_substring("abba")     → 2    # "ab" 또는 "ba"
longest_unique_substring("")         → 0
```
> 힌트: 오른쪽 끝 `right`를 한 칸씩 늘려요. 새 글자가 창 안에 이미 있으면 `left`를 그 글자가 **마지막으로 나온 위치의 다음 칸**으로 옮겨요. (단, `left`가 뒤로 되돌아가면 안 돼요! `"abba"`를 조심하세요.) 글자마다 마지막 위치를 딕셔너리에 저장해 두면 편해요.

### 4. `count_subarrays_with_sum(nums, k)` — 합이 k인 연속 부분 배열의 개수 (난이도: 보통)
정수 리스트 `nums`에서 **연속한 부분 배열** 중 **합이 정확히 `k`**인 것의 **개수**를 돌려주세요. `nums`에는 **음수와 0이 있을 수 있어요.** 시작 위치나 끝 위치가 다르면 서로 다른 부분 배열이에요.
```
count_subarrays_with_sum([1, 1, 1], 2)        → 2    # [1,1] 이 두 군데
count_subarrays_with_sum([1, 2, 3], 3)        → 2    # [1,2], [3]
count_subarrays_with_sum([1, -1, 0], 0)       → 3    # [1,-1], [0], [1,-1,0]
count_subarrays_with_sum([0, 0, 0], 0)        → 6
count_subarrays_with_sum([], 0)               → 0
```
> 힌트: 음수가 있으면 창을 늘렸다 줄이는 방식이 통하지 않아요. 대신 "지금까지의 누적합"이 `s`일 때, 앞에서 누적합이 `s - k`였던 지점이 몇 번 있었는지가 곧 "여기서 끝나는 합 `k`짜리 구간의 개수"예요. `{누적합: 나온 횟수}` 딕셔너리를 `{0: 1}`로 시작해서 세어 보세요.

### 5. `min_window_length(s, t)` — 모든 글자를 포함하는 가장 짧은 구간 (난이도: 조금 어려움)
문자열 `s`의 **연속한 부분 문자열** 중, 문자열 `t`의 **모든 글자를 (개수까지) 포함**하는 가장 짧은 것의 **길이**를 돌려주세요. 그런 부분 문자열이 없으면 `0`이에요. `t`에 같은 글자가 여러 번 있으면 그 개수만큼 필요해요. (`t`는 빈 문자열이 아니에요)
```
min_window_length("ADOBECODEBANC", "ABC") → 4    # "BANC"
min_window_length("a", "a")               → 1
min_window_length("a", "aa")              → 0    # 'a'가 2개 필요한데 1개뿐이에요
min_window_length("aab", "ab")            → 2    # "ab"
min_window_length("abc", "d")             → 0
```
> 힌트: `Counter(t)`로 필요한 개수를 센 뒤, `right`를 늘리며 창에 글자를 넣어요. **필요한 글자를 모두 채우면** 창의 길이를 기록하고, `left`를 오른쪽으로 줄여 가며 "아직도 다 채워져 있는지" 확인해서 더 짧게 만들어 보세요. 모자라지는 순간 다시 `right`를 늘려요. 채워진 글자 종류 수(`have`)와 필요한 종류 수(`need`)를 비교하면 매번 전체를 확인하지 않아도 돼요.
