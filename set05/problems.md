코딩테스트에 자주 나오는 **스택 / 큐 / deque**를 연습해요.

- 큐: 먼저 넣은 것이 먼저 나와요 (FIFO). `collections.deque`의 `append()`, `popleft()`를 쓰세요. (`list.pop(0)`은 느려요!)

### 1. `is_valid_brackets(s)` — 올바른 괄호 (난이도: 쉬움)
`(` `)` `[` `]` `{` `}` 로만 이루어진 문자열이 **올바른 괄호열**이면 `True`, 아니면 `False`를 돌려주세요.
- 여는 괄호는 **같은 종류의 닫는 괄호**로 닫혀야 해요.
- 괄호는 **올바른 순서**로 닫혀야 해요. (`"([)]"`는 안 돼요)
- 빈 문자열은 올바른 괄호열이에요.
```
is_valid_brackets("()[]{}") → True
is_valid_brackets("{[]}")   → True
is_valid_brackets("(]")     → False
is_valid_brackets("([)]")   → False
is_valid_brackets("")       → True
```
> 힌트: 여는 괄호는 스택에 넣고, 닫는 괄호가 나오면 스택의 맨 위와 짝이 맞는지 확인하세요. 마지막에 스택이 비어 있어야 해요.

### 2. `remove_adjacent_duplicates(s)` — 짝 지어 없애기 (난이도: 쉬움)
소문자 문자열에서 **바로 옆에 있는 같은 글자 두 개**를 찾아 지우세요. 지우고 나서 새로 붙은 글자끼리 또 같으면 그것도 지워요. 더 이상 지울 게 없을 때의 문자열을 돌려주세요.
```
remove_adjacent_duplicates("abbaca") → "ca"    # bb 제거 → "aaca" → aa 제거 → "ca"
remove_adjacent_duplicates("aaa")    → "a"     # aa 제거 → "a"
remove_adjacent_duplicates("abba")   → ""
remove_adjacent_duplicates("abc")    → "abc"
```
> 힌트: 글자를 하나씩 스택에 넣되, 스택의 맨 위와 같은 글자면 넣지 말고 맨 위를 `pop` 하세요.

### 3. `josephus(n, k)` — 요세푸스 문제 (난이도: 보통)
`1`번부터 `n`번까지 `n`명이 원을 이루어 앉아 있어요. `1`번부터 시작해서 **`k`번째 사람**을 계속 제거해요. (제거된 다음 사람부터 다시 센다)
마지막까지 **살아남는 사람의 번호**를 돌려주세요. (`n >= 1`, `k >= 1`)
```
josephus(7, 3) → 4     # 제거 순서: 3, 6, 2, 7, 5, 1 → 4번이 남음
josephus(5, 2) → 3     # 제거 순서: 2, 4, 1, 5 → 3번이 남음
josephus(1, 1) → 1
josephus(6, 1) → 6     # 1, 2, 3, 4, 5 순서로 제거
```
> 힌트: `deque`를 만들고, `k-1`번 `rotate(-1)`(맨 앞 사람을 맨 뒤로)한 다음 `popleft()`로 한 명을 제거하세요. 이걸 한 명이 남을 때까지 반복해요.

### 4. `next_greater(nums)` — 오른쪽의 더 큰 수 (난이도: 보통)
각 위치 `i`에 대해, **오른쪽에 있는 수 중 `nums[i]`보다 "엄격하게" 큰 첫 번째 수**를 찾아 리스트로 돌려주세요. 그런 수가 없으면 `-1`이에요. (같은 값은 큰 수가 아니에요)
```
next_greater([2, 1, 2, 4, 3]) → [4, 2, 4, -1, -1]
next_greater([1, 2, 3])       → [2, 3, -1]
next_greater([3, 2, 1])       → [-1, -1, -1]
next_greater([1, 1, 1])       → [-1, -1, -1]
```
> 힌트: 이중 반복문은 `nums`가 길면 느려요. **인덱스를 담은 스택**을 쓰세요. 새 수 `x`가 오면, 스택 맨 위 인덱스의 값이 `x`보다 작은 동안 `pop`하면서 그 자리의 답을 `x`로 채우면 돼요.

### 5. `largest_rectangle(heights)` — 히스토그램에서 가장 큰 직사각형 (난이도: 조금 어려움)
너비가 `1`이고 높이가 `heights[i]`인 막대들이 나란히 붙어 있는 히스토그램이 있어요. 이 안에 그릴 수 있는 **가장 큰 직사각형의 넓이**를 돌려주세요. 직사각형은 **연속된 막대들**로만 만들 수 있고, 높이는 그 막대들 중 가장 낮은 막대의 높이예요. 막대가 없으면 `0`이에요. (높이는 `0` 이상의 정수)
```
largest_rectangle([2, 1, 5, 6, 2, 3]) → 10    # 높이 5, 6 두 칸 → 5 × 2
largest_rectangle([2, 4])             → 4
largest_rectangle([5, 5, 5, 5])       → 20
largest_rectangle([])                 → 0
```
> 힌트: 높이가 **증가하는 동안** 인덱스를 스택에 쌓다가, 낮은 막대를 만나면 스택에서 꺼내며 "그 막대를 높이로 하는 가장 넓은 직사각형"의 넓이를 계산해요. 끝에 높이 `0`짜리 막대를 하나 덧붙이면 남은 것도 한꺼번에 처리돼요.
